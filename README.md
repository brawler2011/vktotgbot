# VK to Telegram Bot (VK ➔ TG Bridge)

Бот для автоматической трансляции постов и комментариев из группы ВКонтакте (например, университетской группы по Истории [vk.com/irs2027](https://vk.com/irs2027)) в Telegram-канал.

Построен на **`python-telegram-bot` (v22+)** и нативной связке **«Канал + Группа обсуждений»**:
* 📢 **Посты** (текст, фотоальбомы, прикрепленные документы PDF/Word, опросы/видео) публикуются в ленту **Telegram-канала**.
* 💬 **Комментарии из ВК** автоматически отправляются **в ветку комментариев соответствующего поста** в Telegram с указанием кликабельного имени автора.

---

## 🚀 Быстрый старт

### 1. Подготовка конфигурации

Клонируйте проект или перейдите в папку проекта и создайте `.env`:

```bash
cp .env.example .env
```

Откройте `.env` в любом редакторе и укажите ваши данные:
```ini
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHANNEL_ID=@your_channel_name
VK_ACCESS_TOKEN=vk1.a.your_service_token_here
VK_GROUP_DOMAIN=irs2027
```

## 🔑 Инструкция: Как получить токены и настроить Telegram

### Шаг 1. Получение токена ВКонтакте (Сервисный ключ доступа)
Так как группа открытая, вам **не нужно** вводить логин и пароль от своего аккаунта. Достаточно постоянного сервисного ключа:
1. Перейдите на [dev.vk.com](https://dev.vk.com) и войдите в свой ВК.
2. Нажмите кнопку **«Создать приложение»** (или «Мои приложения» ➔ «Создать»).
3. Выберите тип: **Standalone-приложение** (или просто приложение), укажите любое название (например `History Bot`).
4. В левом меню перейдите в раздел **«Настройки»**.
5. Найдите поле **«Сервисный ключ доступа»** (*Service Token*), нажмите «Показать» и скопируйте его в `VK_ACCESS_TOKEN` в файле `.env`.

### Шаг 2. Создание и настройка Telegram-бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Задайте имя и юзернейм боту, скопируйте полученный токен в `TELEGRAM_BOT_TOKEN` в `.env`.
3. Отключите приватность групп (чтобы бот видел автофорварды постов в группе обсуждений):
   * В [@BotFather](https://t.me/BotFather) отправьте `/mybots` ➔ выберите вашего бота ➔ **Bot Settings** ➔ **Group Privacy** ➔ нажмите **Turn off**.

### Шаг 3. Настройка Telegram-канала и обсуждений
1. Создайте **Telegram-канал** (например, «История 2027»).
2. Зайдите в **Управление каналом** ➔ **Обсуждение** ➔ нажмите **«Добавить группу»** (создайте новую группу для комментариев, например «Обсуждение Истории»).
3. **Добавьте бота администратором:**
   * В **Канал**: добавьте бота в администраторы с правом **«Публикация сообщений»** (*Post messages*).
   * В **Группу обсуждений**: добавьте бота в администраторы с правом отправки сообщений.

## 🐳 Запуск через Docker Compose (Рекомендуется)

```bash
# Сборка и запуск в фоновом режиме
docker compose up -d --build

# Просмотр логов работы
docker compose logs -f

# Остановка
docker compose down
```

База данных сохраняется в локальной папке `./data/bot.db`, поэтому при перезапусках контейнера история не теряется.

---

## 🐍 Запуск без Docker (напрямую через Python)

Требуется Python 3.10+:

```bash
# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python3 main.py
```

## ⚙️ Параметры конфигурации (`.env`)

| Параметр | Обязательный | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `TELEGRAM_BOT_TOKEN` | Да | - | Токен бота от `@BotFather` |
| `TELEGRAM_CHANNEL_ID` | Да | - | Юзернейм канала (`@channel`) или ID (`-100...`) |
| `TELEGRAM_DISCUSSION_ID` | Нет | *Автоопределение* | ID привязанной группы обсуждений (если не указан, бот определит сам) |
| `VK_ACCESS_TOKEN` | Да | - | Сервисный ключ приложения ВК с [dev.vk.com](https://dev.vk.com) |
| `VK_GROUP_DOMAIN` | Да | `irs2027` | Короткое имя или цифровой ID группы ВК |
| `POLL_INTERVAL` | Нет | `60` | Интервал проверки обновлений в секундах |
| `INITIAL_POSTS_COUNT` | Нет | `5` | Количество постов для синхронизации при первом запуске с пустой БД |
| `DATABASE_PATH` | Нет | `data/bot.db` | Путь к файлу SQLite базы данных |

## 💡 Особенности работы

* **Обработка вложений:** фото отправляются одиночными сообщениями или альбомами (`send_media_group`), методички и документы (PDF, DOCX) загружаются как файлы в канал, видео и опросы оформляются кликабельными ссылками.
* **Ветки комментариев:** при выходе поста Telegram автоматически дублирует его в группу обсуждений. Бот ловит это служебное событие, запоминает ID ветки и все входящие комментарии из ВК пересылает именно туда с помощью `reply_to_message_id`.
* **Упоминания и авторы:** комментарии содержат кликабельное имя автора (`💬 Иван Иванов: ...`), а внутренние ссылки ВК вида `[id123|Имя]` аккуратно преобразуются в HTML-ссылки.

## 🔄 CI/CD деплой по SSH (GitHub Actions)

В проекте настроен автоматический пайплайн [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml), который при каждом `git push` в ветку `main` (или `master`) проводит синтаксическую проверку и автоматически обновляет бота на вашем сервере по SSH.

### 1. Настройка SSH ключа на сервере
На вашем локальном компьютере (или сервере) сгенерируйте пару ключей (без пароля):
```bash
ssh-keygen -t ed25519 -C "github-actions-deploy" -f deploy_key
```

* Публичный ключ (`deploy_key.pub`) добавьте на ваш сервер в файл `~/.ssh/authorized_keys`.
* Приватный ключ (`deploy_key`) скопируйте — он понадобится для GitHub Secrets.

### 2. Подготовка проекта на сервере
Подключитесь к серверу и один раз склонируйте репозиторий:
```bash
cd ~
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> vktotg
cd vktotg
cp .env.example .env
nano .env  # заполните токены
```

### 3. Добавление секретов в GitHub
В вашем репозитории на GitHub перейдите в **Settings** ➔ **Secrets and variables** ➔ **Actions** ➔ **New repository secret** и добавьте:

| Имя секрета | Значение | Пример |
| :--- | :--- | :--- |
| `SSH_HOST` | IP-адрес или домен вашего сервера | `194.87.123.45` |
| `SSH_USER` | Пользователь на сервере | `root` или `ubuntu` |
| `SSH_PRIVATE_KEY` | Содержимое приватного ключа целиком | `-----BEGIN OPENSSH PRIVATE KEY----- ...` |
| `SSH_PORT` | *(Опционально)* SSH-порт сервера | `22` (по умолчанию) |
| `SERVER_PATH` | *(Опционально)* Путь к папке проекта на сервере | `/root/vktotg` или `~/vktotg` |

Теперь при каждом коммите в ветку `main` GitHub Actions автоматически подключится к серверу, обновит код через `git reset --hard` и перезапустит `docker compose up -d --build`.
