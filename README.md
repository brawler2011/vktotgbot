# VK to Telegram Bot (VK ➔ TG Bridge)

Бот для автоматической трансляции постов и комментариев из группы ВКонтакте (например, университетской группы [vk.com/irs2027](https://vk.com/irs2027)) в топик (тред) супергруппы Telegram.

Построен на **`python-telegram-bot` (v22+)** и работе с **топиками супергрупп (форум)**:
* 📢 **Посты** (текст, фотоальбомы, прикрепленные документы PDF/Word, опросы/видео) публикуются напрямую в указанный **топик супергруппы**.
* 💬 **Комментарии из ВК** автоматически отправляются **ответом на соответствующий пост** внутри этого же топика с кликабельным именем автора.

## 🚀 Быстрый старт

### 1. Подготовка конфигурации

Клонируйте проект или перейдите в папку проекта и создайте `.env`:

```bash
cp .env.example .env
```

Откройте `.env` в любом редакторе и укажите ваши данные:
```ini
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHAT_ID=-1001234567890
TELEGRAM_TOPIC_ID=123
VK_ACCESS_TOKEN=vk1.a.your_service_token_here
VK_GROUP_DOMAIN=irs2027
```

## 🔑 Инструкция: Как получить токены и настроить Telegram

### Шаг 1. Получение токена ВКонтакте (Сервисный ключ доступа)
Так как группа открытая, вам **не нужно** вводить логин и пароль от своего аккаунта. Достаточно постоянного сервисного ключа:
1. Перейдите на [dev.vk.com](https://dev.vk.com) и войдите в свой ВК.
2. Нажмите кнопку **«Создать приложение»** (или «Мои приложения» ➔ «Создать»).
3. Выберите тип: **Standalone-приложение** (или просто приложение), укажите любое название (например `History Bot`).
4. В левом меню перейдите в раздел **«Настройки»**.
5. Найдите поле **«Сервисный ключ доступа»** (*Service Token*), нажмите «Показать» и скопируйте его в `VK_ACCESS_TOKEN` в файле `.env`.

### Шаг 2. Создание и настройка Telegram-бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Задайте имя и юзернейм боту, скопируйте полученный токен в `TELEGRAM_BOT_TOKEN` в `.env`.

### Шаг 3. Настройка супергруппы (форума) в Telegram
1. В супергруппе (с включенным режимом «Темы» / Forum Topics) создайте или выберите топик для трансляции.
2. Добавьте бота администратором в группу с правом отправки сообщений.
3. Скопируйте ID группы (`-100...`) в `TELEGRAM_CHAT_ID` и ID топика (число `message_thread_id`) в `TELEGRAM_TOPIC_ID`.
   *(Узнать ID топика можно, скопировав ссылку на любое сообщение внутри темы — последнее число в ссылке `t.me/c/.../TOPIC_ID/...` является ID топика).*

## 🐳 Запуск через Docker Compose (Рекомендуется)

```bash
# Сборка и запуск в фоновом режиме
docker compose up -d --build

# Просмотр логов работы
docker compose logs -f

# Остановка
docker compose down
```

База данных сохраняется в локальной папке `./data/bot.db`, поэтому при перезапусках контейнера история не теряется.

---

## 🐍 Запуск без Docker (напрямую через Python)

Требуется Python 3.10+:

```bash
# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python3 main.py
```

## ⚙️ Параметры конфигурации (`.env`)

| Параметр | Обязательный | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `TELEGRAM_BOT_TOKEN` | Да | - | Токен бота от `@BotFather` |
| `TELEGRAM_CHAT_ID` | Да | - | ID супергруппы (`-100...`) или юзернейм |
| `TELEGRAM_TOPIC_ID` | Нет | - | ID топика/треда в супергруппе (message_thread_id) |
| `ADMIN_TG_ID` | Нет | - | Telegram ID администратора для алертов и команды `/status` |
| `VK_ACCESS_TOKEN` | Да | - | Сервисный ключ приложения ВК с [dev.vk.com](https://dev.vk.com) |
| `VK_GROUP_DOMAIN` | Да | `irs2027` | Короткое имя или цифровой ID группы ВК |
| `POLL_INTERVAL` | Нет | `60` | Интервал проверки обновлений в секундах |
| `INITIAL_POSTS_COUNT` | Нет | `5` | Количество постов для синхронизации при первом запуске с пустой БД |
| `DATABASE_PATH` | Нет | `data/bot.db` | Путь к файлу SQLite базы данных |

## 💡 Особенности работы

* **Обработка вложений:** фото отправляются одиночными сообщениями или альбомами (`send_media_group`), методички и документы (PDF, DOCX) загружаются как файлы в топик, видео и опросы оформляются кликабельными ссылками.
* **Ветка комментариев:** комментарии из ВК пересылаются в тот же тред супергруппы прямым ответом (`reply`) на соответствующий пост.
* **Упоминания и авторы:** комментарии содержат кликабельное имя автора (`💬 Иван Иванов: ...`), а внутренние ссылки ВК вида `[id123|Имя]` аккуратно преобразуются в HTML-ссылки.

## 🔄 CI/CD деплой по SSH (GitHub Actions)

В проекте настроен автоматический пайплайн [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml), который при каждом `git push` в ветку `main` (или `master`) проводит синтаксическую проверку и автоматически обновляет бота на вашем сервере по SSH.

### 1. Настройка SSH ключа на сервере
На вашем локальном компьютере (или сервере) сгенерируйте пару ключей (без пароля):
```bash
ssh-keygen -t ed25519 -C "github-actions-deploy" -f deploy_key
```

* Публичный ключ (`deploy_key.pub`) добавьте на ваш сервер в файл `~/.ssh/authorized_keys`.
* Приватный ключ (`deploy_key`) скопируйте — он понадобится для GitHub Secrets.

### 2. Подготовка проекта на сервере
Подключитесь к серверу и один раз склонируйте репозиторий (вручную создавать `.env` на сервере **не нужно** — CI/CD сформирует его автоматически из секретов GitHub):
```bash
cd ~
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> vktotg
```

### 3. Добавление секретов в GitHub
В вашем репозитории на GitHub перейдите в:  
**Settings ➔ Secrets and variables ➔ Actions ➔ New repository secret**

#### Параметры подключения к серверу:
| Имя секрета | Обязательный | Описание / Пример |
| :--- | :---: | :--- |
| `SSH_HOST` | Да | IP-адрес или домен вашего сервера (`194.87.123.45`) |
| `SSH_USER` | Да | Пользователь на сервере (`root` или `ubuntu`) |
| `SSH_PRIVATE_KEY` | Да | Содержимое приватного SSH-ключа (`-----BEGIN OPENSSH PRIVATE KEY----- ...`) |
| `SSH_PORT` | Нет | Порт SSH (по умолчанию `22`) |
| `SERVER_PATH` | Нет | Путь к папке проекта на сервере (по умолчанию `~/vktotg`) |

#### Переменные окружения приложения (подтягиваются напрямую в бот):
| Имя секрета | Обязательный | Описание / Пример |
| :--- | :---: | :--- |
| `TELEGRAM_BOT_TOKEN` | Да | Токен бота от `@BotFather` |
| `TELEGRAM_CHAT_ID` | Да | ID супергруппы (`-100...`) или юзернейм |
| `TELEGRAM_TOPIC_ID` | Нет | ID топика/треда в супергруппе (`message_thread_id`) |
| `ADMIN_TG_ID` | Нет | Telegram ID администратора для алертов |
| `VK_ACCESS_TOKEN` | Да | Сервисный ключ приложения ВК с [dev.vk.com](https://dev.vk.com) |
| `VK_GROUP_DOMAIN` | Нет | Домен или ID группы ВК (по умолчанию `irs2027`) |
| `POLL_INTERVAL` | Нет | Интервал опроса в секундах (по умолчанию `60`) |
| `INITIAL_POSTS_COUNT` | Нет | Количество постов для первого запуска (по умолчанию `5`) |

> 💡 Также можно передать всё содержимое `.env` целиком в один секрет `ENV_FILE`, если вам так удобнее.

Теперь при каждом коммите в ветку `main` (или `master`) GitHub Actions автоматически подключится к серверу, сгенерирует актуальный `.env` из секретов и перезапустит `docker compose up -d --build`.
